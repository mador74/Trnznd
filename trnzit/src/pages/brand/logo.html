The new “i”: please approve one option

Both options use the same stem width as “r” and “n” (58 units), sit on the same baseline and x-height, and align the dot’s top with the ascender of the “t”. The gap between dot and stem is 33 units. Letter spacing to “z” matches the existing z→n gap (28 units).

Option A (in use): square dot. Matches the flat, square terminals of “t”, “r” and “n”.

Option B: round dot. Echoes the Enso and the rounded bowls of “n” and “d”.

Approval needed. Wordmark lettering is custom artwork. These vectors were traced from the supplied PNG; a type designer should check them against the master artwork (SVG or AI) before final release.

Usage

Clear space

Keep clear space on all sides equal to the wordmark’s x-height (the height of the “n”). [Assumption: the guide’s Clear Space section has no value]

Minimum size

80px wide for digital, 20mm for print (Guide p.22). Below that, use the Enso symbol alone.

Don’t

Don’t stretch, rotate, recolour, outline, add shadows or effects, or set the wordmark in a font (Guide p.22).
