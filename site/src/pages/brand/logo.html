Trnznd logo set

The Enso in the brand gradient (Teal #00D4AA → Electric Blue #0088FF → Violet #6C3AED), with the lowercase trnznd wordmark. Built from the same artwork as the Trnzit set, so the two lock-ups sit together.

Check before final release. The Enso and the letters “t”, “r”, “n” and “z” are the traced artwork used for Trnzit. The “d” was built from the “n”: its upper arch, the same arch turned for the lower bowl, and a stem rising to the height of the “t”. A designer should compare it, and the n→d spacing, with the master trnznd artwork (SVG or AI). Replace assets/logo/ and the sprite if the master differs.

Usage

  • Clear space: on all sides, at least the wordmark’s x-height (the height of the “n”).
  • Minimum size: 80px wide on screen. Below that, use the Enso symbol on its own.
  • Colour: Midnight on light backgrounds, white on dark. The Enso keeps the brand gradient, always in the direction Teal → Electric Blue → Violet.
  • Don’t stretch, rotate, recolour, outline, add shadows or effects, place on busy backgrounds, or set the wordmark in a font.

The Trnzit set uses the same Enso in solid Electric Blue. See Trnzit.
